# Discrete Simulation Models

This repository contains semestral projects developed for the university course **Discrete Simulation**.

All simulations were implemented in **Java**, with graphical interfaces built using **Java Swing**.

---

## 📌 1. Monte Carlo Simulation – Business Cost Optimization

Monte Carlo simulation model for analyzing and optimizing ordering strategies in a supply system.

### Key Features
- Custom implementation of random generators:
  - Discrete & Continuous Uniform
  - Empirical Distributions
- General Monte Carlo simulation core
- Statistical evaluation (mean, standard deviation, confidence intervals)
- Separation of simulation logic and GUI
- Graphical visualization of convergence

---

## 📌 2. Event-Driven Simulation – Furniture Workshop

Event-driven simulation model of a production workshop.

### Key Features
- Custom event-driven simulation core
- Priority queue-based event calendar
- Exponential and Triangular distribution generators
- Chi-Square statistical validation of generators
- Worker utilization statistics
- Interactive Swing GUI with simulation speed control
- Experimental evaluation for optimal workforce configuration

---

## 📌 3. Agent-Oriented Simulation (Documentation Only)

Agent-based simulation model of the same workshop implemented using the proprietary **ABAsim framework**.

Due to licensing restrictions of the ABAsim library, the source code is not included.  
However, full documentation describing:

- Agent hierarchy
- Message-based communication
- Continuous assistants
- Statistical evaluation
- Animation design

is provided in the `agent-based-simulation/docs` folder.
